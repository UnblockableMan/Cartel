About ReduX

ReduX is a static, fast web proxy built by viroda1 & UnblockableMan. It runs entirely in your browser — no server backend required. A Scramjet service worker proxies requests through a WISP transport, so ReduX works on any static host (GitHub Pages, Cloudflare Pages, Netlify, Vercel) without a Node runtime.

Browse the open web, run built-in apps, and play 200+ games from a single page. Type a URL in the search bar above and hit Go to start browsing.
